# List Fold Memory（列表折叠记忆）

> **列表怎么折叠的，关掉笔记再打开还是那样。**

一个 Obsidian 插件：把列表每一次折叠的状态记住。做法不是存到插件自己的文件里，而是在笔记里写一行注释。

[English](./README.md) · **简体中文**

## 它做什么

折叠了一项，关掉笔记，明天再打开 —— 还是折叠着的。

```markdown
- 周会纪要
	%% collapsed:: true %%
	- 数据源整理
	- 口径核对
- 待办
	- 还没折叠的项
```

标记缩进一级，放在它所属那一项的正下方 —— 跟 Logseq 的 `collapsed:: true` 块属性同一个位置。写的时候用 Obsidian 自己的注释语法 `%% … %%`，而且插件在**你所有能看到的地方**都把这种行藏了起来：

- **阅读视图**：Obsidian 本来就不渲染注释，那里就没有。
- **实时预览 / 源码模式**：插件把整行连换行一起从视图里抹掉。不是变淡、不是压扁，是没有 —— 光标把它当成一个原子跳过，打字不可能撞进去。

笔记本身没有别的变化。

## 折叠本身是怎么做的

折叠不是插件自己画的 —— 它调的就是 ⌥S 用的那一套 CodeMirror 折叠。所以你看到的就是 Obsidian 自己的样子：行首那个箭头、行尾那个 `…`、点一下展开的手感，全都一样，没有外来感。

标记和折叠是双向通气的：

- 文件里有标记，打开笔记时那一项就折起来。
- 你自己折 —— ⌥S 也好、点行首箭头也好、怎么折都行 —— 标记会自动写上；展开，标记自动删掉。

所以插件自己的按钮是可选的。你平时怎么折，状态都照样记得住。

## 为什么状态要写在文件里

*更常见的做法是：折叠状态存进插件目录里的 JSON，用行号或者文字指纹去认每一项。写在别人的笔记上的时候，这两种都会崩：*

- *行号 ——上面插任何东西都会错位。而 agent 往日记里追加内容，恰好一直在插东西。*
- *文字指纹 —— 措辞改一点点就断了。*

*写在行里面的注释没有这两个问题：它跟着自己的内容一起走，git、同步、导出、重写都不受影响。这也是它哪怕会动到正文也值得做的原因。*

## 命令

| 命令              | 作用                                |
| --------------- | --------------------------------- |
| 折叠 / 展开光标所在的列表项 | 切换光标所在那一项（没有子项的项折不了）              |
| 折叠本文所有列表项       | 整篇一次全折起来                          |
| 展开本文所有列表项       | 全展开                               |
| 只折叠顶层的列表项       | 只折最外层，里面的层级维持现状                   |
| 清除本文所有折叠标记      | 删掉本文所有标记，还原成没装插件时的原文              |
| 临时露出折叠标记        | 把标记行当普通文字显示出来，看看文件里到底写了什么。再按一次藏回去 |

都可以到「设置 → 快捷键」里绑键。

## 设置

| 设置          | 默认 | 作用                             |
| ----------- | -- | ------------------------------ |
| 鼠标划过时显示折叠按钮 | 开  | 展开着的项，鼠标移到那一行时行尾冒出一个折叠按钮。平时不显示 |
| 折叠按钮上显示后代条数 | 开  | 按钮显示成 `⌄ 3`，数字是它下面一共有几条。折起来之后那个 `…` 是 Obsidian 自己的，改不了 |
| 阅读视图也折叠     | 开  | 阅读视图里也认这些标记，点小标记能展开            |
| 源码模式下也折叠    | 关  | 源码模式无论如何都会把标记藏起来；想让它连列表一起折叠就打开 |
| 临时露出折叠标记    | 关  | 跟同名命令一样                        |

## 怎么清理

插件写下的东西只有一种：每个折叠项一行 `%% collapsed:: true %%`。想清掉有两条路：

- 命令**清除本文所有折叠标记**，当前这篇一次清干净。
- 别的编辑器、全局替换也行 —— 那就是普通的文本行，没有 ID，删掉除了丢掉折叠状态没别的损失。

## 安装

把 `main.js`、`manifest.json`、`styles.css` 复制进 `<库>/.obsidian/plugins/list-fold-memory/`，重启 Obsidian，在「设置 → 第三方插件」里启用。或者用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 从 `MatsuriMW/list-fold-memory` 装上。

## 已知边界

- 只要那一块还在、标记就还在；重写时把整块删了或者换了措辞，折叠状态跟着没 —— 这没法避免。
- 出了 Obsidian（导出成纯 Markdown、用别的编辑器打开），`%% … %%` 是 Obsidian 专有的语法，会当正文显示出来。在意的话先跑一次清除命令。
- 代码块、callout、有序列表、任务清单都认；表格里的列表不折叠。
- 同一篇笔记里，处于同一层级、文本相同的两项会共用一个折叠状态（按这一项自己的文字指纹配对的）。
- 插件只写它自己的标记行，笔记里别的东西一个字都不动。
